# libs/

Kendi Gradle projenizde `elk-logger-1.0.0.jar` dosyasını buraya kopyalayın
(offline paketteki `libs/` dizininden veya repodaki `dist/` dizininden).

Bu örnek repo içinde çalışırken jar bulunamazsa otomatik olarak `../../dist/elk-logger-1.0.0.jar` kullanılır.
Offline pakette bu dizin jar ile birlikte gelir.
